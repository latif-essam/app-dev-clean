# devclean Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A globally-installed macOS CLI (`devclean`) that cleans dev caches for the project you're in, resolving the real project root by walking up from cwd, extensible to new app types via drop-in modules.

**Architecture:** `bin/devclean` sources `lib/detect.sh` (walk-up root resolution) + `lib/core.sh` (registry, output helpers, `nuke`, interactive menu) + every `apps/*.sh` module. Each app module registers markers + targets into the registry. Installed through a local Homebrew tap that puts the repo in `libexec` and writes a `DEVCLEAN_HOME`-exporting wrapper.

**Tech Stack:** Bash (`set -euo pipefail`), Homebrew local tap, pure-bash test harness (no bats).

## Global Constraints

- Command name: `devclean`.
- `set -euo pipefail` in every sourced file's consuming entrypoint; modules must be safe under it.
- Local targets operate on resolved `PROJECT_ROOT`, never raw `cwd`.
- If no registered project root is found up-tree, refuse local targets, exit 1.
- Global targets (`~/` caches) allowed anywhere but behind explicit `y/N`.
- RN logic ported verbatim from `superapp-frontend` `scripts/clean.sh` (branch `feat/sentry-integration`); behavior unchanged.
- Registry-driven: adding an app type = one `apps/*.sh` file + `register_app`, no edits to core/bin.

### Task 5: Entrypoint (`bin/devclean`)

**Files:**
- Create: `bin/devclean`

**Interfaces:**
- Consumes: everything above via `DEVCLEAN_HOME`.
- Produces: executable CLI.

Behavior:
- Resolve `DEVCLEAN_HOME` = `${DEVCLEAN_HOME:-<dir of this script>}`; source `lib/core.sh`, `lib/detect.sh`, all `apps/*.sh`.
- `--help` → usage; `--root` → `resolve_root "$PWD"` then print `PROJECT_ROOT`/`APP_TYPE` (or "not a project") and exit.
- Split requested targets into local vs global (global = gradle-global/xcode-dd/pods-cache).
- If any local target (or no args → menu): require `resolve_root "$PWD"`; on failure print refusal + exit 1; on success `cd "$PROJECT_ROOT"`.
- Global-only invocation with no project: allowed, confirm `y/N`.
- No args → `menu` with detected app's rows, then run `SELECTED_TARGETS` via app run fn + post-clean reinstall prompts (ported).
- Args → run each via detected app's `APP_RUN_FN`.
